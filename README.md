# Skills

This repo is my personal AI agent skills collection.

It contains:
- My own skills
- Skills I got from other people
- Skills inspired by other people

I just put them all in one place so it's easy for me to use.

## Installation

Install a skill using the `skills` CLI:

```bash
# Install the discuss skill
npx skills@latest add ishakantony/skills/discuss

# Install the write-a-skill skill
npx skills@latest add ishakantony/skills/write-a-skill

# Install the write-spec skill
npx skills@latest add ishakantony/skills/write-spec
```

Or install all skills at once:

```bash
npx skills@latest add ishakantony/skills/discuss ishakantony/skills/write-a-skill ishakantony/skills/write-spec
```
